# GitHub portfolio

Published: https://github.com/moses0100/thai-pdf-rescue

Clone and run:

```powershell
git clone https://github.com/moses0100/thai-pdf-rescue.git
cd thai-pdf-rescue
npm ci
npm run build
npm run start
```

CI runs lint, typecheck, unit tests, build and browser tests on push. Public-document QA is opt-in. For deployment, use this repository root; no database or secret is required.
